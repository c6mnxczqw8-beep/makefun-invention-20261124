# One-Sentence Absurd Invention Pitch

Entry for the make.fun bounty "One-Sentence Absurd Invention Pitch".
`main.py` writes one sentence to `entry.txt` in the output directory
(`MAKEFUN_OUTPUT_DIR`, default `/output`).

Final pitch (one sentence, 183 characters):

Meet Rewind, the doorframe that senses you've forgotten why you entered a room, politely pushes you back out, and replays your own muttered plan so the second entrance actually works.

See `CANDIDATES.md` for the twelve candidate pitches drafted first
and the notes on why this one was picked.
